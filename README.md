## Tentang

Situs resmi organisasi KESMA (Kesejahteraan Mahasiswa) HMJMI. Dibangun dengan Tailwind CSS dan animasi ringan.

## Halaman

- `index.html` — beranda
- `angkatan23.html`, `angkatan24.html`, `angkatan25.html` — data angkatan
- `ultah.html`, `tes.html` — halaman tambahan

## Jalankan

Buka `index.html` di browser, atau serve statis (mis. `python -m http.server`).
